## Overview

This notebook walks students through a first encounter with real-ish data using a playful dataset of fictional characters. Students load the data, build intuition with quick plots, and end the session by fitting a linear model.

## Prerequisites

- Familiarity with running a Jupyter cell
- A working Python environment with `pandas`, `matplotlib`, and `statsmodels`

## How to use

Have students work through the notebook in pairs. Pause after the first plot to discuss what they notice. Use the linear-model output at the end as a launching point for the next chapter's lesson.
